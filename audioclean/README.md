# AudioClean — глушилка мата и запрещённых слов

Программа делает ровно одно: берёт видео, находит в речи мат и слова, за
которые TikTok и YouTube Shorts режут показы, и **заглушает их в звуке** —
тишиной или писком.

**Видеопоток не трогается вообще** (`-c:v copy`): картинка остаётся ровно та
же, до последнего байта, а перекодируется только звуковая дорожка. Поэтому
обработка идёт минуты, а не часы, и качество не теряется.

Всё считается локально, ничего никуда не отправляется.

---

## Установка

Нужны **Python 3.9+** и **ffmpeg** в PATH.

```bash
install.bat
```

или вручную:

```bash
py -m pip install -r requirements.txt
```

(если `python` в консоли открывает Microsoft Store — это заглушка Windows;
пользуйтесь `py`, либо выключите её: Параметры → Приложения → Дополнительные
параметры приложений → Псевдонимы выполнения приложения → `python.exe` = Выкл.)

ffmpeg — с https://ffmpeg.org/download.html (или `winget install Gyan.FFmpeg`),
проверить: `ffmpeg -version`.

Модель распознавания речи скачивается сама при первом запуске (`small` —
около 500 МБ).

## Как пользоваться

Обычный путь — вкладка **«Цензура»** режима «Ролики» в Студии (`Студия.bat`).
Она подставляет последний собранный ролик из папки результатов. Отдельное
окно осталось для работы с чужим файлом:

```bash
run.bat
```

При сборке роликов мат глушится сам — за это отвечает галка «заглушить мат
в готовых роликах» на вкладке «Сборка». Вкладка «Цензура» нужна тогда, когда
находки надо посмотреть глазами и снять лишние.

1. **Выбрать файл.** Итоговое имя подставится само (`имя_clean.mp4`).
2. **«1. Найти слова».** Программа достанет звук, распознает речь и сверит
   каждое слово со словарями. Распознанный текст сохранится рядом с видео
   (`имя.mp4.speech.json`), поэтому второй раз тот же файл считается мгновенно.
3. **Проверить список.** В таблице видно время, само слово, сработавшее
   правило, точность распознавания и фразу вокруг него.
   * клик по столбцу «вкл» — выключить лишнее;
   * двойной клик — послушать это место;
   * **«Выключить все такие же»** — снять сразу все срабатывания одного
     правила (например, если в игровом стриме «убил» лишнее);
   * столбец **«точн.»** — насколько распознавалка уверена в слове. Низкое
     число это повод послушать место перед тем, как глушить; `≈` значит, что
     границы слова прикинуты по длине, а не измерены.
4. **«2. Заглушить и сохранить».**

### Слышные начало и конец

По умолчанию глушится **только середина слова**: первые и последние 0,07 с
остаются слышными, поэтому понятно, что слово было и какое, но само оно не
звучит. Настраивается в блоке «Как глушить»:

* галочка **«Слышно начало и конец слова»** и поле **«слышно по краям, с»** —
  чем больше, тем больше слышно; 0,03–0,05 с — едва заметный призвук,
  0,10–0,12 с — слово почти узнаваемо;
* снять галочку — глушить слово целиком, тогда работает поле **«запас вокруг
  слова»**, которое наоборот прихватывает воздух до и после.

Слово короче, чем края плюс `min_mute` (0,1 с), глушится целиком — иначе от
заглушки остаётся только щелчок. Соседние находки с открытыми краями не
склеиваются между собой, чтобы слышные кусочки не пропали.

Кнопка **«Пересчитать по словарям»** заново сверяет уже распознанный текст —
можно менять галочки и свои слова, не распознавая заново.

Настройки запоминаются в `settings.json` рядом с программой.

## Консоль

```bash
python -m audioclean.cli стрим.mp4
python -m audioclean.cli стрим.mp4 -o чисто.mp4 --beep --model medium
python -m audioclean.cli стрим.mp4 --dry-run --report найдено.txt
```

| Ключ | Что делает |
|---|---|
| `-o файл` | куда сохранить (по умолчанию `*_clean`) |
| `--beep` | писк вместо тишины, `--hz 1000` — частота |
| `--keep 0.07` | слышные начало и конец слова, секунды; `--keep 0` — глушить целиком |
| `--pad 0.15` | запас вокруг слова, секунды (работает при `--keep 0`) |
| `--no-ru` / `--no-en` / `--no-platform` | отключить словарь |
| `--word мойстоп` | добавить своё слово (можно несколько раз) |
| `--model medium` | `tiny/base/small/medium/large-v3` |
| `--lang ru` | язык речи, пусто — определить самой |
| `--device cuda` | считать на видеокарте |
| `--dry-run` | только показать найденное, файл не писать |
| `--report файл.txt` | сохранить список найденного |

## Словари

Лежат в папке `wordlists/`, правятся обычным блокнотом.

| Файл | Что внутри |
|---|---|
| `ru_profanity.txt` | русский мат |
| `en_profanity.txt` | английская брань |
| `platform_words.txt` | слова, за которые режут показы: насилие, суицид, наркотики, 18+, оскорбления, азартные игры |
| `whitelist.txt` | исключения: `себе`, `веб`, `мандарин`, `героиня`, `жидкость`, `негромко`… |

Формат строки — **один и тот же во всех четырёх файлах**:

```
слово        основа: (приставка) + основа + любое окончание
~слово       слово с падежным окончанием и ничем больше
=слово       только точное совпадение
re:...       своё регулярное выражение
два слова    последовательность слов
# строка     комментарий, правило выключено
```

Основы проверяются с учётом приставок, поэтому «заебал» ловится, а
«требовать», «вебинар», «себя» — нет.

`~слово` — для тех случаев, где основа берёт лишнее, а точное совпадение
наоборот теряет формы: `~негр` ловит «негра», «негру», «негром», «негров», но
не «негромко»; `~жид` — «жида», «жидом», но не «жидкость». Раньше такие слова
приходилось перечислять по одной форме на строку.

Исключение сильнее словаря и пишется тем же синтаксисом, так что одна основа
закрывает все формы сразу: `мандарин` в `whitelist.txt` снимает и «мандарину»,
и «мандаринами».

Слово нормализуется перед проверкой: регистр, `ё→е`, `сууука`→`сука`,
`xyu`→`хуй`, `бл9ть`→`блять`. Если распознавалка разорвала слово надвое
(«бл» + «ять», «пи» + «здец») — соседние куски проверяются и склеенными.

> Официальных списков запрещённых слов TikTok и YouTube не публикуют.
> `platform_words.txt` собран по их правилам сообщества и опыту авторов —
> это отправная точка, а не закон. Лишнее выключайте прямо в таблице или
> комментируйте строку в файле.

## Что проверялось

На тестовом ролике (1280×720, речь с матом и словом из списка площадок):

| | |
|---|---|
| найдены оба слова с таймкодами | «сука» 0:07, «убью» 0:12 |
| MD5 видеопотока до и после | **совпадает** — картинка не тронута |
| режим «тишина» на заглушённом участке | −180 дБ (цифровая тишина) |
| режим «писк» | 1000 Гц, −31.6 дБ |
| речь вне заглушек | −23.5 дБ до и после, без изменений |
| длительность файла | не изменилась |

Словари после правки основ (прогон `check`-набора):

| | |
|---|---|
| 285 обычных слов (`страховка`, `мандарину`, `негромко`, `жидкость`, `вебинаром`…) | **0 ложных срабатываний** |
| 111 запрещённых слов и форм | найдены все |
| каждое из 286 правил ловит собственную основу | да |
| разорванные слова `бл`+`ять`, `пи`+`здец`, `за`+`ебал` | склеиваются и ловятся |
| слово 10,00–10,60 с при `keep 0.07` | глушится 10,07–10,53 — по 70 мс слышно с краёв |

## Сколько это занимает

* **Распознавание речи** — самая долгая часть: модель `small` на процессоре
  обрабатывает час записи примерно за 10–20 минут. С работающей связкой
  CUDA + cuBLAS считается в разы быстрее (`--device cuda`).
  Второй раз тот же файл — мгновенно, текст берётся из кэша.
* **Сама заглушка** — минуты даже на многочасовом файле: видео копируется
  как есть, перекодируется только звук.

## Структура

```
main.py                 запуск окна
audioclean/
  gui.py                панель Cleaner + оболочка App для отдельного окна
  cli.py                консольный режим
  pipeline.py           связка: звук -> текст -> слова -> файл
  transcribe.py         faster-whisper, таймкоды каждого слова
  profanity.py          словари и сопоставление
  textnorm.py           нормализация слов
  render.py             ffmpeg: видео копируется, звук глушится
  ffmpeg.py             запуск ffmpeg/ffprobe/ffplay, прогресс
  config.py             настройки
wordlists/              словари
```

## Что стоит знать про окно

**`Cleaner` — рамка, а не окно.** Студия кладёт её во вкладку, `App` — в своё
окно; отличаются они только оболочкой. Всё, что касается заголовка, размера
и закрытия, живёт в `App`, в панели этого нет.

**Панель красит свой фон сама.** `tk.Frame` без `background` берёт системный
серый, и в отдельном окне он лез белыми полосами между карточками — там, где
между ними есть зазор. Умолчание — `core.ui.BG`.

**Отложенный `after` снимается в `shutdown`.** Иначе очередь сообщений
просыпается на уже уничтоженном виджете, и Tk отвечает
`invalid command name ..._pump`.

**Журнал закрепляется внизу до таблицы.** Если упаковать его после,
растущая таблица его выдавливает за край.

**Края и внешний запас — взаимоисключающие настройки:** включена «слышно
начало и конец» — работает запас по краям, выключена — внешний запас вокруг
слова. Оба сразу не имеют смысла, поэтому лишнее поле гасится.

Сторож — `tests/clean_test.py`.
