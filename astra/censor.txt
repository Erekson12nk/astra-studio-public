# Список слов для автоцензуры.
# Одно правило на строку. Пустые строки и строки с # игнорируются.
#
# Формат правил:
#   слово     - точное совпадение
#   корень*   - совпадение по началу слова
#   *конец    - совпадение по концу слова
#   *часть*   - вхождение в любое место (ловит приставочные формы:
#               на-, за-, по-, до-, от-, разъ- и так далее)
#   !слово    - исключение, это слово никогда не цензурится.
#               Проверяется раньше всех остальных правил.
#
# Регистр и знаки препинания не важны, буква ё приводится к е.
#
# Что делает цензура: закрывается только середина слова. В субтитрах
# первая и последняя буквы остаются видны, середина заменяется символами.
# Звук глушится тоже в середине: --censor-lead секунд в начале и
# --censor-tail секунд в конце остаются слышны, поэтому понятно,
# какое слово было зацензурено. На коротких словах обе величины
# ужимаются, чтобы середину было что заглушить.
#
# Если ловится лишнее - добавьте слово в исключения строкой с !
# Если что-то пропускается - добавьте корень в форме *корень*
