# Astra — вертикальные ролики 9:16

Нарезает короткие вертикальные клипы из длинных стримов: вебка сверху,
геймплей снизу, караоке-субтитры, заголовок на стыке, автоцензура мата.

## Если вам передали папку с Astra.exe

Устанавливать ничего не нужно — ни Python, ни ffmpeg. Просто запустите
**`Astra.exe`**.
Остальные разделы этой инструкции можно пропустить, кроме «Как пользоваться».

## Установка

Нужны две вещи: Python и ffmpeg.

**1. Python 3.10 или новее** — с [python.org](https://www.python.org/downloads/).
При установке обязательно отметьте галочку **«Add python.exe to PATH»**.

**2. ffmpeg** — любой из двух способов:

```
winget install Gyan.FFmpeg
```

либо скачать сборку с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) и распаковать
так, чтобы получился путь `ffmpeg\bin\ffmpeg.exe` **внутри папки проекта** —
тогда программа найдёт его сама и в систему ставить ничего не нужно.

**3. Запустить `setup.bat`** — он создаст изолированное окружение `.venv`
и поставит библиотеки. Занимает несколько минут, интернет нужен.

## Запуск

Открыть файл **`Astra.exe`** двойным щелчком. Консольных окон не появляется.

Если `Astra.exe` не запускается, попробуйте `run_gui.bat` — он покажет причину.
То же самое открывает `start.pyw`.

## Если ничего не запускается

**Запустите `check.bat`** — он проверит установку и напишет по-русски,
чего не хватает и что сделать. Это первое, что нужно сделать при любой проблеме.

Самые частые причины:

- **Не запускался `setup.bat`** или он прервался на середине.
  Запустите его снова и дождитесь надписи «Done».
- **Python не установлен** либо при установке не отмечена галочка
  «Add python.exe to PATH». Переустановите с python.org, галочку отметить
  обязательно. Версия из Microsoft Store часто идёт без нужных компонентов.
- **Нет ffmpeg.** Программа запустится, но не сможет собрать видео.
- **Двойной щелчок ничего не делает** — расширение `.pyw` не привязано
  к Python. Используйте `run_gui.bat`, он покажет причину.

Если программа падает при запуске, рядом появится файл `start_error.log`
с текстом ошибки — пришлите его автору вместе с выводом `check.bat`.

## Как пользоваться

Окно разбито на три шага: **Что нарезать**, **Кадр**, **Надписи**.
Справа всё время виден предпросмотр — он переключается между результатом
9:16 и исходником с рамками.

### 1. Что нарезать

1. **Выбрать** — указать видео стрима.
2. **Найти моменты** — программа сама предложит лучшие. Два режима:
   - *По громкости* — быстро, по всплескам звука.
   - *По расшифровке* — распознаёт речь кандидатов и собирает текст
     для нейросети (кнопки «Скопировать для ИИ» и «Вставить ответ»).
3. Выбрать момент в списке или задать время вручную.
4. **Смонтировать ролик** — один клип, **Все выбранные** — пакетом
   в папку с автоматическими именами.

### 2. Кадр

**Найти лицо** — программа сама определит вебку и подгонит рамку под неё.

Когда моментов несколько, она сначала разбирается, **кто из лиц на экране
стример**: проходит по всем клипам, сверяет лица между собой и берёт того,
кто встречается чаще всех. Это важно на реакционных стримах, где на экране
всё время чужие лица — из проигрываемого видео, превьюшек, аватаров.
Можно указать эталон явно снимком: `--face-ref фото.jpg`.

Рамки правятся мышью на вкладке предпросмотра «Исходник и рамки»:
протянуть — нарисовать, потянуть изнутри — сдвинуть, колесо — масштаб.

**Вид** — четыре раскладки:

| Вид | Что получается |
|---|---|
| Сама решит | Вебка в углу — два блока; во весь экран — крупный план; вебки нет — только экран |
| Вебка и экран | Два блока друг над другом |
| Только вебка | Крупный план, бока обрезаются |
| Только экран | Экран целиком, сверху и снизу размытые полосы |

Разделение нужно не всегда: под крупный план берите «Только вебка»,
а когда важно, что написано на экране, — «Только экран»: там картинка
вписывается целиком и текст не режется.

**«Сама решит»** (`--layout auto`, стоит в новых профилях) смотрит, где на
экране вебка. Если она развёрнута во весь экран, разделять нечего — иначе
лицо оказывается и сверху, и снизу; программа делает один блок крупным
планом и опускает субтитры вниз кадра. Если вебка сидит в углу — два блока
и субтитры на стыке, как обычно.

А если вебки в кадре нет вовсе — реакция на чужое видео во весь экран,
например, — берётся «Только экран». Раньше программа в этом случае всё
равно строила два блока и ставила наверх первое попавшееся лицо, обычно
чужое. Чтобы это различить, поиск лица переехал перед выбором вида: нет
лица или лицо есть, но опознание говорит «не стример» — значит вебки нет.
Без эталона стримера (нет фото в профиле или не поставлен `onnxruntime`)
отличить чужое лицо не от чего, и всё работает как раньше.

**Где вебка** — ищется по фотографии из профиля, а не по лицу: сличаются
приметы картинки (полки, лампа, подушка за спиной), поэтому находится и
тогда, когда лица не видно или на экране полно чужих лиц. Отсюда же берётся
точная рамка накладки — без неё рамка строилась от лица и захватывала кусок
страницы снизу.

Перед нарезкой пакетом программа проходит по всем клипам по паре кадров и
запоминает, где вебка на этом стриме обычно сидит. Дальше слабая находка,
совпавшая с этим местом, считается верной. Раньше это место набиралось по
ходу нарезки, и первым клипам оно не доставалось. Кадров на клип задаёт
`--anchor-samples` (по умолчанию 4), выключается флагом `--no-anchor`.

### 3. Надписи

Субтитры стоят на стыке блоков — шрифт, размер, цвета обычного и
произносимого слова, сколько слов помещать в строку. Чтобы передвинуть
субтитры, кликните по кадру предпросмотра.

Заголовок необязателен и рисуется у верхнего края, чтобы не спорить
с субтитрами. Оставьте поле пустым, если он не нужен.

Тут же — язык и модель распознавания, автоцензура и вырезание пауз.

## Файлы, которые можно править

- **`censor.txt`** — список слов для цензуры. Формат описан внутри файла.
  Слово заменяется символами в субтитрах, звук глушится. Отключается галочкой.

## Что стоит знать

- **Видеокарта.** Ускоряет распознавание речи. Нужны драйверы посвежее и пакеты:
  `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`. Без них всё работает
  на процессоре, просто медленнее. Кодирование видео тоже задействует
  видеокарту автоматически, если драйвер её поддерживает.
- **Модель распознавания речи** скачивается сама при первом запуске
  (около 1.5 ГБ для `medium`) и потом лежит в кеше.
- **Модель детекции лица** (`blaze_face_short_range.tflite`, ~230 кБ)
  тоже скачивается сама при первом нажатии «Найти лицо».
- Первый запуск дольше обычного из-за этих загрузок.

## Командная строка

Всё то же доступно без интерфейса:

```
python auto_vertical_editor.py stream.mp4 01:12:30 01:13:05 clip.mp4
python auto_vertical_editor.py stream.mp4 --scan 8 --batch --out clips
python auto_vertical_editor.py stream.mp4 --scan 8 --scan-mode transcript --brief brief.txt
python auto_vertical_editor.py stream.mp4 --select answer.txt --brief brief.txt --out clips
python auto_vertical_editor.py stream.mp4 --timecodes moments.txt --out clips
python auto_vertical_editor.py stream.mp4 --timecodes moments.txt --layout cam --out clips
```

`--layout` выбирает раскладку: `split` (по умолчанию, вебка над экраном),
`cam` (только вебка, крупным планом) или `screen` (только экран, вписанный
целиком, с размытыми полосами). В `screen` лицо вообще не ищется.

Субтитры по умолчанию встают на стык блоков, а без разделения — низко
в кадре. Двигаются флагом `--subs-y`.

Опознание стримера: `--face-ref фото.jpg` задаёт эталон явно, `--face-match`
меняет строгость (по умолчанию 0.4; свой человек обычно даёт 0.5-0.85,
чужой — меньше 0.15), `--no-face-id` выключает совсем. Нужен `onnxruntime`;
без него программа работает как раньше и говорит об этом. Модель
`arcface_w600k_mbf.onnx` (13.6 МБ) скачивается сама при первом запуске.

Полный список параметров: `python auto_vertical_editor.py --help`

## Сборка комплектов для передачи

Два варианта, оба запускаются двойным щелчком:

- **`build_bundle.bat`** — архив с программой, ffmpeg и библиотеками.
  Получателю нужен установленный Python. Размер 166 МБ без библиотек
  или около 600 МБ вместе с ними.
- **`build_exe.bat`** — автономная папка с `Astra.exe`.
  Получателю не нужно вообще ничего. Размер около 1.5 ГБ,
  результат в `dist\Astra\`.

## Что не переносится вместе с папкой

Папку проекта можно копировать и передавать целиком. Не переносятся только
скачанные модели и `.venv` — на новом компьютере нужно заново запустить
`setup.bat`, а модели подтянутся сами при первом использовании.
