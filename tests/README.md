# Проверки

```
py tests\run.py            прогнать всё
py tests\run.py studio     только наборы, где в имени есть "studio"
py tests\media.py          собрать тестовые файлы и показать где они
```

Тестовые видео и звук делаются сами при первом запуске (`ffmpeg` + системный
синтезатор речи на Windows) и кешируются во временной папке. Речь нужна
по-настоящему: на синусоиде whisper не даёт слов.

Часть наборов требует окружения с `cv2`, `mediapipe` и `faster-whisper` —
`run.py` сам находит `astra/.venv`, если он есть рядом.

## Что проверяется

| набор | о чём |
|---|---|
| `learn_test.py` | связка баз clipper и astra: совпадение по времени, черновики, свежие просмотры, повторный запуск без дублей |
| `studio_test.py` | окно: вкладки, таймкоды, кнопка расшифровки, журнал |
| `cache_test.py` | общий кеш: один запуск whisper вместо трёх |
| `rolik_test.py` | режим «Ролики» целиком: стрим → clipmaker → цензура без повторного распознавания |
| `studio_build_test.py` | сборка роликов через само окно |
| `face_test.py` | выбор вебки: устойчивое лицо против самого крупного |
| `layout_test.py` | раскладки кадра: два блока, только вебка, только экран |
| `webcam_test.py` | поиск вебки по снимку профиля, крупный план |
| `profile_test.py` | профили: фото, срок хранения, защита оценённых клипов |
| `rerank_test.py` | реранкер: обучение на сравнениях и оценках |
| `gui_layout_test.py` | окно astra: «Сама решит» и покраска выпадающих списков |
| `adopt_test.py` | клипы из astra возвращаются в базу clipper |
| `embed_test.py` | монтаж astra внутри Студии: источник, моменты, автономное окно |
| `cachedir_test.py` | разбор кеша: виды файлов, осиротевшие перекладки, удаление |
| `anchor_test.py` | якорь вебки: собирается до рендера, крупный план в него не идёт |
| `packages_test.py` | раскладка репозитория: пакеты в корне, точки входа их находят |
| `encoder_test.py` | выбор кодировщика: объяснение отказа по-русски, откат на процессор |
| `pairs_test.py` | подбор пар: свежие клипы видно, самопар и дублей нет |
| `studio_sense_test.py` | отбор по смыслу через clipper (долгий, в `run.py` не включён) |

## Сравнение до и после

`snapshot/` — не тесты, а снимки поведения. Ими проверялся каждый переезд
в ядро: снять эталон до правки, повторить после, сверить.

```
bash tests/snapshot/snapshot.sh <папка> before     до правки
bash tests/snapshot/snapshot.sh <папка> after      после
```

`spy.py` подставляет вместо модели распознавания «шпиона», который
записывает параметры вызова. Это единственный способ сверять
расшифровку: на синтетической речи она не детерминирована, потому что
astra не передаёт `condition_on_previous_text=False`.

Известные расхождения, которые не ошибки: 7 в наборе ffmpeg (тексты
сообщений и типы исключений) и 6 в asr (два — умолчания самой
faster-whisper, четыре — следствие пропуска слов без таймкода).

## Чего проверки НЕ доказывают

- **Публикация с настоящими ключами.** Сеть везде подменена.
- **Как выглядит окно.** Проверяется, что строится и логика работает;
  вёрстку надо смотреть глазами.
- **Скорость на настоящем стриме.** Все замеры на файлах до 30 минут.
