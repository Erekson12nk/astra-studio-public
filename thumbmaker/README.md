# Thumb Maker

Собирает превью для ролика: **фон — превью исходного видео**, поверх — **вырезанный
стример**. Лицо берётся либо с **загруженной фотографии**, либо из **стрима** —
тогда программа сама ищет кадр с самой яркой эмоцией. Плюс крупная подпись и бейдж.

Как в образце: фон из игры + отзеркаленный стример справа + крупный текст капсом
внизу во всю ширину + «#2».

## Что происходит внутри

1. **Превью** — `yt-dlp` отдаёт список превьюшек ролика, берётся самая большая (maxres).
2. **Лицо с фото** — если загружена фотография, шаги 2–4 пропускаются: лицо ищется
   прямо на ней (пороги при этом мягкие — выбирать не из чего, снимок один).
   Дальше сразу шаг 5.
3. **Кадры стрима** — `yt-dlp` даёт прямую ссылку на поток, `ffmpeg` быстрым seek'ом
   вытаскивает N кадров по всему хронометражу (параллельно, сам стрим не скачивается).
4. **Эмоция** — MediaPipe Face Landmarker считает 52 блендшейпа мимики
   (`jawOpen`, `mouthSmile`, `browInnerUp`, `eyeWide`, …). Из них собирается рейтинг
   «яркости»: открытый рот, поднятые брови, широкие глаза — плюс; моргание и
   закрытый рот — минус. Штрафы за мелкое лицо, профиль и смазанный кадр
   (резкость сравнивается с медианой по этому же стриму, а не с абсолютным порогом).
5. **До-скан** — вокруг лучших моментов кадры берутся ещё плотнее: пик эмоции живёт
   доли секунды и на грубой сетке легко проскакивает.
6. **Вырезка** — MediaPipe Selfie Multiclass отделяет человека от фона, остаётся
   только та фигура, в которой находится лицо; край смягчается.
7. **Сборка** — холст 1920×1080 (или до 4K), притемнение со стороны стримера, тень.
   Стример отзеркален, чтобы смотрел в кадр; обводки по умолчанию нет. Подпись —
   капсом, шрифтом Impact (за ним Arial Black), внизу кадра во всю ширину поверх
   стримера. Кегль подбирается сам, длинный текст переносится по словам, предлоги не
   висят в конце строки, `*слова в звёздочках*` выделяются жёлтым. Под текстом —
   затемнение снизу; можно выбрать плашку под строками, пергамент или ничего.
   Всё оформление (отступы, тени) масштабируется вместе с холстом.

## Установка

```
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Нужен **ffmpeg** в PATH. Модели MediaPipe (≈20 МБ) скачиваются сами при первом запуске в `models/`.

## Интерфейс

```
run_ui.bat
```

или `.venv\Scripts\python.exe app.py` — откроется страница в браузере.
Вставляете ссылку на ролик, выбираете, откуда брать лицо — **«Фото стримера»**
(перетащить файл или вставить из буфера) или **«Ссылка на стрим»** — и жмёте
«Собрать превью». В режиме стрима внизу появится галерея кандидатов: клик по любому
пересобирает превью с этой эмоцией. Кнопка «Пересобрать» применяет настройки
вёрстки, не запуская скан заново. Готовый файл — в `out/`.

Рядом — выбор **разрешения** (1280×720 … 3840×2160), что положить **под текст**
(затемнение снизу, плашка под строками, пергамент, ничего) и ползунок «Рисунок
пергамента». В настройках — «Отзеркалить стримера» и обводка. В поле текста работает
Shift+Enter — принудительный перенос строки, `*слово*` пишется жёлтым.

## Командная строка

Лицо с фотографии:

```
.venv\Scripts\python.exe cli.py --video <ссылка на ролик> --photo streamer.jpg --caption "HOW TO FISH" --badge "#2"
```

Лицо из стрима:

```
.venv\Scripts\python.exe cli.py --video <ссылка на ролик> --stream <ссылка на стрим> --caption "HOW TO FISH" --badge "#2"
```

| Ключ | Что делает | По умолчанию |
|---|---|---|
| `--photo` | фото стримера — источник лица | — |
| `--stream` | ссылка на стрим — альтернатива `--photo` | — |
| `--samples` | сколько кадров сканировать по стриму (только с `--stream`) | 48 |
| `--top` | сколько кандидатов оставить | 8 |
| `--pick` | какого кандидата поставить на превью (1 — лучший) | 1 |
| `--side` | сторона стримера, `right` / `left` | right |
| `--scale` | высота стримера от высоты кадра | 0.98 |
| `--offset-x`, `--offset-y` | сдвиг вырезки в долях кадра | 0 / 0.02 |
| `--outline` | толщина белой обводки, 0 — без неё | 0 |
| `--no-mirror` | не зеркалить стримера | — |
| `--mirror-auto` | зеркалить, только если стример смотрит из кадра | — |
| `--layout` | `classic` — превью во весь кадр, `card` — карточкой с рваным краем слева сверху | classic |
| `--face-height` | крупный план: высота лица от высоты кадра, 0 — стример целиком | 0 |
| `--no-shadow` | убрать тень | — |
| `--min-face` | мин. доля ширины кадра, которую занимает лицо | 0.05 |
| `--max-yaw` | допустимый поворот головы, 0 — строго в камеру | 0.45 |
| `--res` | размер холста, `ШИРИНАxВЫСОТА` | 1920x1080 |
| `--font` | свой .ttf вместо Impact | — |
| `--plate` | под текстом: `band` затемнение, `box` плашка, `torn` рваная полоса, `parchment`, `none` | band |
| `--parchment-seed` | другой узор пятен и рваного края | 7 |
| `--save-parts` | сохранить ещё превью-фон и все кадры-кандидаты | — |

`--photo` и `--stream` взаимоисключающие, один из них обязателен. В режиме стрима
CLI печатает список кандидатов с таймкодом, оценкой и типом эмоции — удобно выбрать
другой момент через `--pick`. В `--caption` перенос строки пишется как `\n`:
`--caption "первая строка\nвторая"`. Если у `--out` расширение `.png`, файл
сохраняется без потерь, иначе — JPEG качества 97 без цветовой субдискретизации.

Про «максимальное разрешение» честно: холст можно взять хоть 4K, но резкость
исходников этим не поднять. Фон — это превью с YouTube (обычно 1280×720), лицо —
кадр стрима (тянем до 1080p) или ваша фотография. Крупный холст нужен, чтобы не
мылились текст и подложка, а фото стримера в 4K пошло в дело целиком;
фон при этом растянется. Для самого чёткого результата берите фото покрупнее.

## Тонкая настройка

Веса мимики, размеры холста и стиль сборки — в [thumbmaker/config.py](thumbmaker/config.py):
`FaceConfig.weights` (что считать «яркой эмоцией»), `ScanConfig` (глубина скана),
`ComposeConfig` (вёрстка превью, зеркало, подложка, цвет акцента, seed пергамента).

Шрифт по умолчанию — системный Impact; свой указывается через `--font` /
`ComposeConfig.font_path`. Без Impact программа берёт Arial Black, затем Arial Bold,
в самом конце — декоративный `assets/fonts/Unsightly.ttf`. Текстура пергамента рисуется кодом
(`compose.parchment_texture`), картинки-подложки не нужны.

## Поддерживаемые источники

**Фото** — любой обычный формат (JPG, PNG, WebP; PNG с прозрачностью тоже).
Нужен снимок, где стример смотрит примерно в камеру и лицо не перекрыто.

**Стрим** — всё, что умеет yt-dlp: YouTube (в т.ч. прямые эфиры и VOD), Twitch, Kick, VK Видео и др.
Для прямого эфира стрим сканируется по живому краю (последние ~90 секунд).
